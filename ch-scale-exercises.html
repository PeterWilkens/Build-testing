    Chapter 16 Scale Exercises

    This chapter presents a set of melodic scale exercises based on the Cmaj7 tonal centre. Each exercise trains a different intervallic pattern — diatonic thirds, triads, and diatonic seventh chord arpeggios — and should be practised slowly before increasing tempo. Once secure in C major, transpose to all twelve keys.
